# Cuong Image Trainer

Trang web luyện nhận diện ảnh với đáp án tự import và đồng hồ đếm ngược.

## Dùng

Mở `index.html`. Chọn CSV (cột `image,answer`, hoặc hai cột không tiêu đề) và các ảnh tương ứng. Câu hỏi được xáo ngẫu nhiên khi nạp và mỗi lần bắt đầu lại.

## Lưu trữ

Các bản HTML cũ được lưu trong `archive/`.

## Dữ liệu cá nhân

Không commit ảnh hoặc CSV chứa đáp án riêng vào repo công khai.
